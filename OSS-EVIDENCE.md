# AunoForge OSS Evidence Ledger

This file is intentionally conservative. It records facts that can be verified from the public repository and leaves adoption fields unclaimed until measurements exist.

## Project purpose

AunoForge is a provider-neutral open-source maintainer toolkit for issue triage, bug reproduction planning, evidence-aware review, deterministic checks, release drafting, and declarative maintenance recipes.

## Verifiable launch facts

- License: Apache-2.0.
- Runtime target: Node.js 20+.
- CLI commands: init, doctor, triage, reproduce, review, release, recipes/recipe utilities.
- Initial provider adapters: mock, Codex/OpenAI, Claude/Anthropic.
- Builtin recipes at source launch: 11.
- Security invariants encoded as regression tests: 10.
- GitHub Action defaults: read-only permissions and no PR comment.
- Destructive merge/publish/delete automation: not exposed in v0.1.0.
