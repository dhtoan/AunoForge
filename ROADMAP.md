# AunoForge Roadmap

The roadmap describes direction, not promised dates.

## v0.1 — trustworthy maintainer CLI

- CLI: init, doctor, triage, reproduce, review, release.
- Provider adapters: mock, Codex/OpenAI Responses API, Claude/Anthropic Messages API.
- Versioned recipe v1 contract and builtin recipes.
- Evidence validation, deterministic checks, safe-mode policy, security regression suite.
- Read-only-by-default GitHub Action.

## v0.2 — GitHub Action improvements

Improve artifact/report ergonomics, action packaging, and opt-in comment workflows while preserving least privilege and fork safety.

## v0.3 — provider and recipe SDK stability

Refine external adapter interfaces, fixture tooling, compatibility tests, and contributor documentation based on real community use.

## Deferred until evidence justifies them

MCP server, IDE integrations, GitHub App, web dashboard, enterprise policy bundles, richer marketplaces, and autonomous code-changing workflows remain intentionally deferred.
